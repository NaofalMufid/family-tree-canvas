Kebijakan Privasi / Privacy Policy

Family Tree Canvas — Aplikasi Pembuat Pohon & Kanvas Silsilah Keluarga

Pembaruan Terakhir / Last Updated: 26 November 2026 Pengembang / Developer: @kamingsun

1 Ringkasan Arsitektur & Prinsip Privasi

Family Tree Canvas dibangun dengan arsitektur 100% client-side, local-first, dan zero-backend. Seluruh pemrosesan data silsilah keluarga—termasuk nama, tahun lahir/wafat, catatan relasi, maupun foto profil—berjalan sepenuhnya di dalam memori browser pada perangkat Anda sendiri.

Aplikasi ini tidak memiliki server database pusat. Pengembang tidak pernah mengumpulkan, menerima, menyimpan, melihat, maupun memiliki salinan atas data silsilah atau foto apa pun yang Anda buat.

Architecture & Privacy Overview: Family Tree Canvas is built on a 100% client-side, local-first, zero-backend architecture. All processing of family tree data—including names, birth/death dates, relationship notes, and profile photos—occurs entirely inside your browser's local memory on your own device. We do not operate any central database server, and the developer has zero access to, copies of, or visibility into your family tree data or photos.

2 Penyimpanan Lokal & Enkripsi Sisi Klien

  • Penyimpanan Perangkat Lokal: Untuk kenyamanan fitur auto-save, data Canvas dan foto yang telah dikompresi secara otomatis disimpan secara lokal di penyimpanan browser perangkat Anda menggunakan teknologi standar web (IndexedDB dan/atau localStorage).
  • Enkripsi Opsional (AES-GCM 256-bit): Saat melakukan Export file backup silsilah ke format .json, Anda dapat mengaktifkan perlindungan Password opsional. Proses enkripsi dilakukan langsung di perangkat Anda menggunakan antarmuka bawaan browser Web Crypto API dengan derivasi kunci PBKDF2 (SHA-256) dan algoritma AES-GCM 256-bit.
  • Tanpa Pemulihan Password: Karena password dan kunci enkripsi tidak pernah dikirim ke server mana pun, hanya Anda yang dapat membuka file backup terenkripsi tersebut.

Local Storage & Client-Side Encryption: Auto-saved tree data and locally compressed photos are stored exclusively on your device's browser storage (IndexedDB / localStorage). When exporting your data to a .json backup file, you may optionally encrypt the payload directly in your browser using the native Web Crypto API (PBKDF2 SHA-256 key derivation + AES-GCM 256-bit). Passwords never leave your device.

3 Integrasi Google Drive API (Opsional) & Kebijakan Limited Use

Fitur sinkronisasi atau backup ke Google Drive bersifat sepenuhnya opsional dan hanya aktif atas tindakan eksplisit Anda (saat Anda menekan tombol Simpan ke Drive atau Buka dari Drive).

  • Izin Akses Minimal (Least Privilege): Aplikasi hanya meminta ruang lingkup (scope) minimal https://www.googleapis.com/auth/drive.file. Dengan izin ini, aplikasi hanya dapat melihat, membuat, dan memperbarui file .json silsilah yang secara spesifik dibuat atau dibuka melalui Family Tree Canvas, serta tidak dapat membaca, mengubah, atau menghapus file pribadi lainnya di Google Drive Anda.
  • Koneksi Langsung Browser-ke-Google: Token otorisasi OAuth sementara hanya disimpan di memori sesi browser Anda untuk berkomunikasi langsung dengan API Google Drive tanpa perantara server pihak ketiga.
Google API Services User Data Policy — Limited Use Disclosure

Family Tree Canvas's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, data accessed via https://www.googleapis.com/auth/drive.file is used solely to provide user-initiated backup and restore functionality for your family tree files. We never sell Google user data, use it for advertising or profiling, allow human reading of user data, or share/transfer it to any third-party servers.

4 Tanpa Pelacakan (Zero Tracking & Zero Telemetry)

  • Tanpa Cookie Pelacak: Aplikasi tidak memasang tracking cookies maupun pengidentifikasi lintas situs.
  • Tanpa Analytics Pihak Ketiga: Tidak ada skrip pelacak perilaku pengguna (seperti Google Analytics, Meta Pixel, atau perangkat telemetri tersembunyi) yang dimuat di dalam aplikasi ini.

Zero Tracking: Family Tree Canvas does not use tracking cookies, third-party analytics scripts, advertising trackers, or hidden telemetry. Your browsing activity and family tree edits remain strictly private.

5 Kendali & Penghapusan Data oleh Pengguna

Anda memegang kendali penuh atas seluruh data Anda setiap saat. Anda dapat menghapus seluruh data lokal aplikasi kapan saja melalui tombol Reset Canvas di dalam aplikasi atau dengan membersihkan data situs (Site Data / Browser Storage) pada pengaturan browser Anda. Jika Anda pernah menghubungkan akun Google Drive, Anda juga dapat mencabut akses aplikasi kapan saja melalui halaman Google Account Permissions.

User Control & Data Deletion: You retain full ownership and control of your data. You can erase all local data at any time using the in-app Reset action or by clearing browser site storage, and revoke optional Google Drive access anytime via your Google Account Permissions.
